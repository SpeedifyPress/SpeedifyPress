The npm notices come from the exact installed package versions (downloaded by npm); Composer licences were downloaded from the source commits pinned in composer.lock. Notices cover direct JavaScript dependencies and the shared Vue, Popper and datepicker modules; not every library is used in every edition.

When updating dependencies, refresh these notices to match the versions being distributed.
